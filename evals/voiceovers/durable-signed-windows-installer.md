# durable-signed-windows-installer

1. The install page recommends the correct package for the current computer.

2. An Intel Mac gets the Intel recommendation; uncertain Macs get two clear choices instead of a false recommendation.

3. Windows offers x64 and ARM64, delivered as an organization-named ZIP containing the setup executable and its configuration.

4. Windows reports a verified publisher, and extracting or renaming the executable does not lose its organization configuration.

5. A newly created team link does not break a package that was already downloaded.

6. After installation, OpenWork opens directly at the organization’s sign-in without requesting a server URL.
