# lightweight-branded-org-installer — one lightweight installer produces a fully branded first launch

The desktop has public internet access. The organization Den deployment may not, so Den only prepares the lightweight organization installer and never fetches or proxies the standard desktop application.

1. From my organization’s download page, I choose Mac or Windows and receive the lightweight OpenWork Installer with my organization setup—there is no bundled standard DMG or EXE inside the download.

2. In Finder or Explorer, the installer already has the native OpenWork application icon, and the installer window uses that same familiar OpenWork identity.

3. I launch the installer and see my organization name and exact server before making changes, then explicitly confirm the installation.

4. The installer uses the desktop’s public internet connection to download the normal standard OpenWork application directly from its release, while the Den server never fetches or proxies that large artifact.

5. On the very first launch, the installed application already targets the correct organization server and displays the company app name, wordmark, and square Dock or taskbar icon—no generic first run or restart required.
