# skill-share-coworker-consume — Owner shares a weekly report skill and a coworker gets it through OpenWork Connect

Context (not narrated): The owner publishes the skill through Den plugin and marketplace primitives. The desktop app is driven as the coworker, who signs in with a handoff code, confirms cloud delivery, and reloads to prove the Connect-delivered skill remains active.

1. Before the coworker clicks anything, the owner has already shared Weekly Report Skill to the whole organization. The marketplace and plugin records both point to the same skill content.

2. Now the coworker signs in from the desktop app with the handoff code and lands in the same Acme Robotics workspace.

3. In Settings, the organization Marketplace shows Weekly Report Skill as available to this coworker.

4. The coworker opens the card and sees Weekly Report Skill already Active through OpenWork Connect, with one skill included and no local install step.

5. The coworker's own access token can read the shared weekly-report source text from the server, and the Marketplace resolved view counts it as a skill.

6. After a full reload, the organization Marketplace still shows Weekly Report Skill as Runs in cloud, proving the shared skill stays active through Connect.
