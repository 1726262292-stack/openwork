# windows-last-workspace-deletion - Last workspace stays deleted on Windows

1. With multiple workspaces in the sidebar, I remove one and OpenWork keeps the remaining workspace ready to use.

2. I remove the final workspace, and OpenWork returns to a clean welcome screen with no deleted workspace left behind.

3. After waiting, the welcome screen stays quiet: there is no stale workspace activity and no unexpected model picker.

4. I restart OpenWork, and the empty welcome screen returns exactly as I left it.
